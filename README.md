# 🐾 Adopción E-commerce

> Plataforma web diseñada para gestionar y facilitar el proceso de adopción de mascotas de manera ágil, conectando refugios y adoptantes.

---

## 🛠️ Tecnologías Utilizadas

### **Backend**
* Python / FastAPI
* Endpoints y autenticación segura con bcrypt

### **Frontend**
* Interfaz moderna de usuario optimizada para la experiencia web.
